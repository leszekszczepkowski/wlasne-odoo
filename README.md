# szczepkowski.ai: wtyczki do kursów

Marketplace wtyczek Claude Code do kursów szczepkowski.ai.

- `plugins/wlasne-odoo`: „Kurs Start: własne Odoo Community z Claude’em”. Opis i polecenia: [plugins/wlasne-odoo/README.md](plugins/wlasne-odoo/README.md).

Instalacja w Claude Code (zakładka Code, folder kursu):

```
/plugin marketplace add leszekszczepkowski/wlasne-odoo
/plugin install wlasne-odoo@szczepkowski-ai
```

Aktualizacja: `/plugin marketplace update szczepkowski-ai`. Instalacja z ZIP-a: plik `INSTALACJA.txt`.

Wtyczka działa z pakietem instalacyjnym i dodatkami, które kursant pobiera po zalogowaniu na stronie kursu.
